## Publicación
Es un sitio estático. Puede subirse a cualquier hosting o integrarse en WordPress mediante una página/plantilla.

## Criterio de cálculo
El resultado principal utiliza directamente la columna de “Sueldo de bolsillo” de la grilla AMET aportada, según cargo y antigüedad.
En “Horas cátedra” el importe unitario se multiplica por la cantidad ingresada.

## Actualización de futuras grillas
Editar data.js o generar un nuevo conjunto de datos conservando la estructura. Se recomienda mantener versiones históricas por mes.

## Control recomendado antes de publicar
Verificar cada importe contra el PDF/imagen fuente original y confirmar institucionalmente logos, textos legales, teléfonos, email y criterios de liquidación.


## Versión multicargo
La calculadora inicia vacía. Permite agregar, repetir y eliminar cargos; cada renglón tiene antigüedad propia. Ejemplo: dos cargos TC.
